# Figma MCP truncation recovery receipt

FVR-001-A2 records that native Figma Make retrieval returned 200 current resources, while its transport inserted literal `…N tokens truncated…` markers into 47 large mirror files. Those files are incomplete evidence, not source-authority failures.

The machine-readable [manifest](FIGMA_MCP_TRUNCATION_MANIFEST.json) records every affected mirror, its SHA-256, reachability, disposition, and proof. It is generated by `node scripts/design/write-figma-mcp-truncation-manifest.mjs` from the preserved native mirror tree.

Two active modules are recovered only from the authorized current Make v39 mirrors:

- `PublicFlows.tsx`: native prefix 22,746 bytes and suffix 23,424 bytes match the mirror, except terminal newline; recovered SHA-256 is `755c6ed62916608e427eb9f65b5ecb4ea34258fedb1f8a02a3602e4f159aa23c`.
- `RequestCenterRoute.tsx`: native prefix 21,611 bytes and suffix 23,051 bytes match the mirror, except terminal newline; recovered SHA-256 is `995704cc4dcd198d1d469dfe5e0b7c335003219080d6ca194c9657b1ce03943e`.

The corrupted brand-data modules now resolve through accepted backend media contracts: `/brand/combined-lockup`, `/brand/login-background`, and `/brand/usc-logo`. The corrupt prototype-only current-cover module is deleted. The Figma-native Current section uses `GET /api/public/advertisements`, real published media URLs, and real alternate text for loading, populated, empty, request-error, and media-error states. The logistics hero and its animation remain separate.

The 41 truncated `src/imports/**` generated/reference files are retained only under `output/design/figma-make-source`; their active `src/frontend/imports/**` counterparts were removed. No transport marker may be reachable from the active production entry.
