# HAU-USC Logistics v0.7.2 DOL Quick Start

Status: production operational at v0.7.2. Use only the official production URL;
the permanent staging sandbox is test-only and displays `STAGING TEST ENV`.

1. Open the official HAU-USC Logistics staff URL supplied by the release
   operator. Verify the page says `Production` and `v0.7.2` before signing in.
2. Sign in with your assigned Access ID or approved verified email. Never share
   passwords, temporary credentials, verification codes, or private tracking
   links.
3. If first-login activation appears, complete only the approved profile fields
   and create a unique password. A pending or rejected application does not
   grant staff access.
4. Confirm the workspace and operational scope shown in the shared header. If
   either is wrong, stop and contact an Administrator; do not continue in a
   different committee's records.
5. Use My Profile for permitted contact, username, or password changes. Identity
   and affiliation corrections use the governed correction request.
6. Use Request Center for Event or Activity work, or Office Inventory or Pantry
   work. Quantities must be whole numbers. Review the receipt before leaving.
7. Use Lending, Release, and Inventory only through visible authorized actions.
   Never compensate for a blocked action by editing records outside the system.

Report unexpected access, another person's information, raw errors, duplicate
records, incorrect release identity, or failed handoff immediately under
`docs/PRODUCTION_INCIDENT_GUIDE.md`.
