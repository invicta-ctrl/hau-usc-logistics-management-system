- Awwwards' homepage experienced a client-side failure during inspection, strengthening the no-route-blocking-animation rule.
- Magic UI and default Codrops downloadable demos publish MIT terms, but no third-party code reuse is proposed. 21st.dev licensing was not authoritatively confirmed and remains reference-only.
