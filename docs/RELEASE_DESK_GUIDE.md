# Release Desk Guide

Release Desk is an internal, server-authorized handoff surface.

1. Open the accepted request and confirm the linked event/day/activity,
   recipient, department, quantities, and available reservation or received
   deliverable.
2. Recheck physical stock and the server-projected remainder. Never release
   against a stale browser view.
3. Record the actual recipient and role, released quantities, notes, and any
   governed confirmation evidence.
4. Submit once and verify the release/history entry. A replay must return the
   original result rather than post another movement.
5. For a correction, append the authorized reversal/adjustment path. Never edit
   ledger, release, status-history, audit, or evidence rows directly.

System Owner may open Release Desk through normal validation; role switching
does not impersonate another account or bypass capability checks.
