### B. Confirmed defect repair

A defect is eligible only when all conditions hold:

1. It is reproduced on the verified current baseline or exact staging candidate.
2. It materially blocks or corrupts rollout/daily use, authorization, privacy,
   data integrity, workflow completion, or recovery.
3. It is not a cosmetic preference or future enhancement.
4. The smallest safe fix fits the existing schema/architecture or has a separately
   approved amendment.
5. A regression test can be added before or with the fix where practical.

Eligible severity is normally P0/P1 or a tightly justified P2 that prevents
ordinary staff use. Cosmetic P2/P3 work waits for the design/hardening roadmap.

### C. Documentation and handoff

regression test, and the smallest repair. Amend this specification only if the
proven root cause materially changes accepted scope. Append `CHANGELOG.md` only
with verified facts, update `PROJECT_STATUS.md`, `docs/WORK_CONTINUATION.md`, and
the canonical current chain together, and retain a concise `DO NOT REPEAT` block.

## Work model and bug-fix method

- One active writer: CODEX.
- At most two concurrent read-only subagents for bounded independent review; they
  never edit shared files.
- At most three implementation slices and no more than three clean commits ahead
  of `main` for the release branch.
- Target one to three hours per slice; hard stop at four hours.
- One primary objective per slice and one clean commit per slice where practical.
- Use targeted reads, focused tests, capped output, and unchanged exact evidence.
- Stop with an exact handoff if the same blocker survives two bounded repair
  attempts.

For each eligible blocker: reproduce deterministically, identify the authoritative
boundary, add a regression test first when practical, fix only the confirmed
cause, review the complete logical diff, run focused tests, rerun reproduction,
check adjacent privacy/auth/data invariants, and update exact evidence/handoff.
Never change behavior from a screenshot, assumption, stale chat, or historical
branch.
