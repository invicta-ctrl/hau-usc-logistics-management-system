## Frozen frontend contract

The v5 prototype directory is read-only visual source. Do not intentionally
change its HTML structure, CSS, theme, tokens, colors, typography, spacing,
sizing, layout, hierarchy, components, controls, copy, route names/order,
icons, images, assets, borders, radii, shadows, animation, responsive behavior,
loading appearance, empty-state wording, or error-state appearance.

Do not run Hallmark or Impeccable. CSS/theme edits are not authorized. If an
integration technical break cannot be solved through existing selectors,
event delegation, adapters, state, or non-visual attributes, stop before any
CSS or visual change.

Do not copy UI components, layouts, controls, copy, or visual patterns from the
current playground or production frontend. Backend capabilities not represented
by an existing v5 control remain preserved server-side and are recorded as
`BACKEND_CAPABILITY_NOT_EXPOSED_BY_V5`.
